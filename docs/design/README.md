# Design records

Working records from building Ampersand v1: the design audit, the critique and
its confirmation round, the ui-ux checklist, and the app icon notes. They are
kept as written at the time.

The screenshots these records cite (`docs/design/screenshots/`) are not in
this repository. They showed a real working configuration, so they were left
out when the project was published. Current screenshots, taken with a
fictional configuration, are in [`docs/screenshots`](../screenshots).
